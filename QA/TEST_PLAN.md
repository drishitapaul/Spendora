# Spendora Test Plan

## Objective
Validate the core functionality, usability and data handling of the Spendora finance tracking application.

## Scope
- Authentication
- Transaction management
- Dashboard
- Input validation
- UI navigation
- Database validation

## Testing Types
- Functional Testing
- Manual Testing
- Regression Testing
- UI Testing
- Negative Testing
- Database Testing
- Automated Testing

## Testing Approach
Manual test cases are designed for core workflows. Critical user flows are automated using Python, Selenium and Pytest.

## Tools
- Python
- Selenium WebDriver
- Pytest
- SQLite
- Git/GitHub
